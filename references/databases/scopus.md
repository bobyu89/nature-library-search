# Scopus (supplementary)

Entry: config `scopus.entry`. Use Advanced search syntax (`TITLE-ABS-KEY(...)`, `PUBYEAR > 2014`) and submit
via the results URL. In the 2026-10 run Scopus served as a sensitivity check only: record the count, scan the
first 20 by relevance and by citations for anything the main databases missed, and report it in the PRISMA
diagram header ("敏感度檢查：Scopus 補充檢索（n = …），未發現新增符合條件之文獻"). The results list does not
show DOIs. If the user wants Scopus records in the dedup set, export RIS from the results page in ≤ 2,000-record
chunks and treat it like the other RIS files.
